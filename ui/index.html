不知道權限要選哪幾個？

指定這個客戶的帳戶，加入以下「帳戶／編輯」權限：

  • Workers 指令碼（Workers Scripts）
  • Workers KV 儲存空間（Workers KV Storage）
  • Workers R2 儲存空間（Workers R2 Storage）

不要選成「Workers 代理程式設定」。另外需要在帳戶內開通 R2 與 workers.dev；條款與付款設定由你自行確認。

L

把通知送到你的 LINE

開始前，請先完成雲端部署。

  1. 設定 LINE 的 Webhook

    將下方網址貼到 LINE Developers → Messaging API → Webhook URL，開啟 Use webhook，再按 Verify。

  2. 用 LINE 傳送配對碼

    先加入機器人好友，再用私人對話傳送下方整段文字。Verify 成功不代表已完成配對。

  3. 等這個畫面顯示「LINE 已連接」

    這裡會自動檢查。配對碼 15 分鐘有效，過期請重新按「開始配對」。

先傳一則通知看看

會傳送通知文字與所選相機的圖片，使用 LINE 訊息額度。

尚未在本機介面執行測試。

最後，讓 UniFi 觸發通知

不一定要門磁。也可以使用相機支援的人員、動作或越線偵測。

  1. 開啟 UniFi Protect → Alarm Manager，選擇事件和來源。
  2. 新增 Webhook 動作，方法選 POST，貼上完整網址。
  3. 儲存後重新打開，確認規則已啟用、方法與網址仍正確。
  4. 實際開門或走入偵測範圍，確認手機收到畫面。
ⓘ

Test Alarm 重複測試請至少間隔 60 秒。測試成功不代表現場規則已生效，還需要實際觸發一次。
